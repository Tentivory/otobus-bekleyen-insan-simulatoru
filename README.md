# Otobüs Bekleyen İnsan Simülatörü

## Giriş

Bu proje, insanlık tarihinin en büyük gizemlerinden birini çözmek için tasarlanmıştır: **Otobüs neden hiç gelmez?**

Bilimsel araştırmalar (yani benim kafamdan uydurduklarım) göstermiştir ki, otobüs bekleyen insanların %99.7'si aslında paralel bir evrende yaşamaktadır. Bu simülatör, o paralel evreni sizin bilgisayarınızda yeniden yaratır.

## Özellikler

- Otobüsün "geliyor" demesini sağlar ama asla gelmez.
- Her 3 saniyede bir umut aşılar, sonra umudu çalar.
- Gerçekçi Türkçe şikayet üretir.
- GitHub Copilot bu kodu onaylamıştır (muhtemelen gülerek).

## Kullanım

```bash
python simulator.py
```

Ve bekleyin. Sonsuza kadar.

## Neden Bu Proje?

Çünkü bazen hayatta en önemli şey, otobüsün gelmemesidir. Bu proje o gerçeği kabul ettirir.
